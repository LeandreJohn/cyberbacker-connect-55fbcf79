# Cyberbacker Connect

Build a modern SaaS web application called Cyberbacker Client Success Platform.

The platform serves two primary audiences:

Clients

Internal Cyberbacker Staff

The application should have a professional enterprise design similar to modern SaaS products such as HubSpot, Salesforce, Monday.com, and Stripe Dashboard.

Requirements:

Responsive desktop and mobile design

Modern dashboard layout

Sidebar navigation

Top navigation bar

Notification center

User profile menu

Dark mode support

Clean enterprise UI

Component-based architecture

Ready for FastAPI backend integration

User Roles:

Client

Recruiter

Facilitator

Support Agent

Finance Team

Administrator

Executive

Create the following primary navigation sections:

CLIENT FEATURES

Dashboard

My Cyberbackers

Hiring Marketplace

Attendance

Performance Reports

Support Center

Knowledge Base

Contracts

Billing

Rewards & Coupons

Settings

INTERNAL FEATURES

Client Management

Cyberbacker Management

Recruitment Pipeline

Support Ticket Management

Finance Dashboard

Analytics Dashboard

Executive Dashboard

System Administration

Generate all pages with realistic placeholder data and modern UX patterns.

Do not implement backend logic.

Assume all data will be provided by FastAPI REST APIs.
